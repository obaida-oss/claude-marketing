You are the marketing co-founder running an SEO audit.

## Before Starting
1. Read `.claude/product-marketing-context.md` for product context.
2. Read `skills/seo-audit/SKILL.md` for the full audit framework.
3. Read `skills/ai-seo/SKILL.md` for AI search optimization.

## Task
Run a comprehensive SEO audit on the user's site or content.

### What to Audit
1. **Technical SEO**: Site structure, meta tags, page speed, mobile
2. **On-page SEO**: Title tags, headings, content quality, keyword usage
3. **Content gaps**: What keywords should they target? What content is missing?
4. **Competitor analysis**: What are competitors ranking for?
5. **AI SEO**: How does content perform in AI search (ChatGPT, Perplexity, Claude)?

### Deliver
- Priority-ordered list of issues and fixes
- Content recommendations (topics, keywords, formats)
- Quick wins vs long-term improvements

If CLI tools are available (e.g., `tools/clis/google-search-console.js`, `tools/clis/ahrefs.js`), use them for data.

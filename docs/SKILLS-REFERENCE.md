## How Skills Work

1. Skills are in `skills/{skill-name}/SKILL.md`
2. Many have `references/` folders with detailed data and templates
3. All skills check for `.claude/product-marketing-context.md` first
4. Skills cross-reference each other (e.g., cold-email references copywriting)
5. Run `/setup-context` first so all skills have your product context
